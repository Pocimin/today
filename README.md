# today

a tiny journal that wakes up a few times a day, writes one line, and goes
back to sleep. the stats below regenerate on every wake-up.

it's quiet, it's predictable, and it never misses a day. mostly i made this
so the computer does one productive thing a day while i do the opposite.

## files

- `entries/` — one markdown note per day
- `scripts/update.py` — the whole brain. stdlib only, no dependencies
- `data/` — facts, words and quotes it draws from
- `.github/workflows/today.yml` — the cron that keeps it alive

## why

a streak of green dots needs consistency, and i have a computer that owes
me nothing. so the computer is consistent instead.
